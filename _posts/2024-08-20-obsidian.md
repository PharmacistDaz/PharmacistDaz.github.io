I'm frequently finding that the simpler the structure of any notes I make, the easier it is to search back through them.

At work I extensively use OneNote - as the NHS is very Microsoft focussed.<br>
The problem is, searching in OneNote is frankly "pants".

So I have been keeping, or attempting to keep notes in Obsidian (<https://obsidian.md/>) - which uses a simpler format of "Markdown" for the note content. Then some clever people use various CSS snippets and addons to expand outwards from that simple base.

The beauty about MarkDown is that it is fairly readable format in it's own right - almost a plain text file when not seen through the eyes of a programme that can "read" MD.

Anyway, I find I've been able to extract content from Webpages and keep simpler versions in my own archive, which means I can then use more powerful searches to find what I need in those references.

But today I've been learning about Callouts, and the ability to have an Icon for the Callout type, and also to make them folding. So I've produced myself a reference page of all the different types.


And hopefully here's the MarkDown file that you might want to use to have your own reference file.

I'd be interested to hear if anyone else is using the Obsidian software, and the use cases.

Enjoy.

### Supported types

You can use several callout types and aliases. Each type comes with a different background color and icon.

To use these default styles, replace `info` in the examples with any of these types, such as `[!tip]` or `[!warning]`. Callout types can also be changed by right-clicking a callout.

Unless you [Customize callouts](https://help.obsidian.md/Editing+and+formatting/Callouts#Customize) , any unsupported type defaults to the `note` type. The type identifier is case-insensitive.
